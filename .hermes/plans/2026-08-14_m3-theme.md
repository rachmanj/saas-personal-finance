# Material Design 3 (M3) Theme Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Restyle the Personal Finance PWA to follow Google Material Design 3 principles (dynamic tonal color, larger shape scale, tone-based surfaces, Material typography & motion) while keeping the existing Ant Design 5 component tree intact.

**Architecture:** Pragmatic M3-on-AntD approach — do NOT migrate to MUI. We express M3 purely through AntD's `ConfigProvider` token system (seed color + generated tonal palette) plus a small global CSS layer (shape, typography, surface tones, motion). This keeps 100% of existing components/pages working with zero functional regression.

**Tech Stack:** React 19, AntD 5 (ConfigProvider `theme`), Inertia, Vite, Google Fonts (Roboto Flex), plain CSS variables.

---

## Current State

- `resources/js/app.jsx` — `ConfigProvider` uses only `theme.darkAlgorithm` + `theme.defaultAlgorithm`, no custom tokens, no seed color (default AntD blue `#1677ff`).
- `resources/js/Contexts/ThemeContext.jsx` — `theme` state is `'dark'` | `'light'`, default `'dark'`.
- `resources/views/app.blade.php` — hardcoded `data-theme="dark"`, hardcoded `background:#141414`.
- `resources/js/Layouts/AuthenticatedLayout.jsx` — Sider + Header + Content; sidebar brand "KeuanganKu".
- Radius default AntD (6px), buttons/cards square-ish, no tonal surfaces.

---

## M3 Design Decisions (single source of truth)

| M3 concept | Mapping in this app |
|---|---|
| **Seed color** (dynamic color) | `token.colorPrimary` — use a Material green/teal seed `#00897B` (teal 600) — finance-friendly, distinct from AntD default blue |
| **Tonal palette** | AntD auto-generates primary/neutral palettes from seed — keep |
| **Shape scale** | `borderRadius: 12` (cards), `borderRadiusLG: 16`, `borderRadiusSM: 8`; buttons `borderRadius: 20` (pill-ish), inputs `borderRadius: 12` |
| **Tone-based surfaces** | Override `colorBgContainer`, `colorBgElevated`, `colorFillSecondary` with slight primary-tint; use `colorBgContainer` for cards instead of flat `#141414` |
| **Typography** | Load **Roboto Flex** via Google Fonts; set `fontFamily` token; headings `fontWeight 600` |
| **Motion** | Enable `theme.motion` default (AntD already smooth); set `motionDurationMid: '0.3s'` |
| **Error/tertiary** | `colorError: '#BA1A1A'` (M3 red), `colorWarning: '#FFB300'`, `colorSuccess: '#00897B'` |
| **Elevation** | Replace hard shadows with tonal elevation (`colorBgElevated` + subtle `boxShadow`) |

## Task Breakdown

### Task 1: Centralize M3 token theme in `app.jsx`

**Objective:** Define the M3 seed + token set once, applied to both dark and light algorithms.

**Files:**
- Modify: `resources/js/app.jsx:27-46`

**Step 1:** Add a shared `m3Tokens` object (M3 seed teal + shape + typography + semantic colors):

```js
const m3Tokens = {
    // M3 seed — teal (finance)
    colorPrimary: '#00897B',
    colorInfo: '#00897B',
    colorSuccess: '#00897B',
    colorWarning: '#FFB300',
    colorError: '#BA1A1A',
    // M3 shape scale
    borderRadius: 12,
    borderRadiusLG: 16,
    borderRadiusSM: 8,
    // Typography (Roboto Flex loaded in blade)
    fontFamily: "'Roboto Flex', 'Roboto', system-ui, sans-serif",
    // Motion
    motionDurationMid: '0.3s',
    motionDurationSlow: '0.4s',
};
```

**Step 2:** Apply tokens to both algorithms inside `ConfigProvider theme`:

```js
theme={{
    algorithm: currentTheme === 'dark' ? theme.darkAlgorithm : theme.defaultAlgorithm,
    token: m3Tokens,
    components: {
        Button: { borderRadius: 20, controlHeight: 40 },
        Card: { borderRadiusLG: 16 },
        Input: { borderRadius: 12 },
        Select: { borderRadius: 12 },
        Modal: { borderRadiusLG: 20 },
        Tag: { borderRadiusSM: 999 },
    },
}}
```

**Step 3 (verify):** `npm run build` → success.

**Step 4 (commit):**
```bash
git add resources/js/app.jsx && git commit -m "feat(m3): seed color + shape + typography tokens"
```

## Risks & Tradeoffs

- **AntD ≠ full M3** — this delivers the M3 *look and feel* (dynamic tonal color, shape, type, motion) without a full MUI rewrite. If Iwan wants pixel-perfect Material You, that's a separate large migration (MUI + emotion), high risk.
- **Google Fonts requires internet** — the PWA may be used offline; provide a system-ui fallback (already in `fontFamily` token). Optionally self-host the font later.
- **Seed color choice** — teal `#00897B` is a proposal; Iwan can swap to any seed (Material You supports any seed color). Low risk, easy to change one value.
- **No backend change** — Telegram bot, OCR, CRUD untouched.
